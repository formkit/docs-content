## 2.4.0

### November 6, 2026

### &nbsp;&nbsp;&nbsp;✨ Highlights

- **`fillForm()`** (`@formkit/addons`): the write side of `describeForm()` for AI agents and tests. Fill by address (or nested objects), give option labels, wait for validation, optionally submit — and get a JSON report of what's valid, invalid (including server errors from `setErrors()`), unknown, unmatched or skipped. Never echoes values. [Docs](https://formkit.com/plugins/describe-form#filling-a-form-with-fillform)
- **Combined validation visibility**: `validation-visibility="blur dirty"` shows a `required` error when someone tabs out of an empty input *and* checks rules live as soon as they type (#973).
- **Faster mounts**: cheaper event listener registration (~2–3% on large forms).
