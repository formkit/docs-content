## 2.5.0

### November 8, 2026

### &nbsp;&nbsp;&nbsp;✨ Highlights

- **`create-app` speaks React** ⚛️ — `npx formkit create-app my-app --framework react --lang ts` scaffolds Vite + React with `FormKitProvider`, the Regenesis theme and an example form: one line for humans and coding agents alike. `--framework vue` is now an alias for `vite`, and Vue + JavaScript projects get a `formkit.config.mjs` (they were mistakenly given a `.ts` file). (#1787)
- **Big forms mount faster in both frameworks** 🏎️ — two more O(n²) paths are gone (#1792, #1314). React groups/lists no longer clone their whole value on every child commit, and groups/lists no longer recompute `state.empty` on every child commit. Production `pnpm bench`: React 450 inputs 288 → 241ms (−16%), validated 321 → 271ms (−16%), 1500 inputs 1327 → 889ms (−33%); Vue 1500 inputs 1442 → 1289ms (−11%).
- **Security** — `@formkit/cli` now uses `giget` v2, dropping the vulnerable `tar@6` dependency from `create-theme`.
- **Behavior notes** — an empty group/form now *starts* with `context.state.empty === true` in Vue (it previously reported `false` until its first commit). The localStorage plugin now honors its `control` option: with the control field off, the form isn't saved and saved data isn't restored.
