## 2.10.0

### November 24, 2026

### &nbsp;&nbsp;&nbsp;✨ Highlights

- **`toJSONSchema(node)`** (`@formkit/addons`): export any form's shape and validation as JSON Schema (2020-12, or `dialect: 'draft-07'`). Validation rules become real keywords (`required`, `minLength`/`maxLength`, `pattern`, `format`, `enum`, `minimum`/`maximum`); rules JSON Schema can't express are kept in `x-formkit-rules`. Hand it to any LLM tool-calling / structured-output API to fill a form, or validate submissions server-side from the same schema. `strict: true` targets strict structured-output modes (closed objects, optional fields nullable). The WebMCP plugin now uses the same mapping. See the [`describeForm` / `toJSONSchema` docs](/plugins/describe-form).
