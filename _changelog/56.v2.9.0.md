## 2.9.0

### November 21, 2026

### &nbsp;&nbsp;&nbsp;✨ Highlights

- **Named slots in schema** 🎰 — `$cmp` nodes take `slots: { header: [...] }` alongside `children` (the default slot). The component's slot props are in scope for that slot's nodes (`$title`…), just like the default slot. In React each named slot becomes a same-named render-prop. Requested since 2022! (#190)
- **Expose forms to browser agents (experimental)** 🤖 — `createWebMCPPlugin()` from `@formkit/addons` registers `describe` / `fill` (and opt-in `submit`) tools per form via WebMCP (`document.modelContext`, Chrome origin trial), with an input schema generated from your fields. Values withheld by default, passwords refused unless `sensitive: true`, and zero cost in browsers without WebMCP. (#1824)
