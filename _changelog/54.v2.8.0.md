## 2.8.0

### November 19, 2026

### &nbsp;&nbsp;&nbsp;✨ Highlights

- **`__deep__` schema props** 🤿 — schema expressions already worked in nested objects but not inside arrays, so something like a reactive `disabled` on one select option stayed static. Prefix the prop with `__deep__` and every nested object *and* array is parsed: `__deep__options: [{ label: 'Banana', value: 'b', attrs: { disabled: '$outOfStock' } }]`. Opt-in, so literal strings like `'$10'` in ordinary arrays are unaffected. Handy for LLM-generated schemas. Vue and React. (#1506)
- **Accessibility** — messages rendered by `<FormKitMessages>` had `id="undefined-…"`, so an input's `aria-describedby` pointed at nothing once its messages were moved. Fixed in Vue and React.
