## 2.8.1

### November 20, 2026

### &nbsp;&nbsp;&nbsp;✨ Highlights

- **`formkit skill` asks before touching your project** 🔒 — the coding-agent skill installer no longer preselects agents, lists exactly which files it would modify and asks first (default No). In non-interactive shells (agents, CI) it never edits `AGENTS.md` / `CLAUDE.md` unless you pass `--agents codex,claude-code --yes`. The installed skill also pins its refresh command to the version that installed it (`npx formkit@2.8.1 skill`). Thanks @Dimooyoyo for the report. (#1828)
