## 0.131.0

### November 9, 2026

### &nbsp;&nbsp;&nbsp;🚀 Features

- **datepicker**: New `inline` prop renders the calendar directly below the input instead of in a popup. It's always open, picking a date keeps it visible (a panel `sequence` starts over), it never steals focus on load, and Tab moves on normally. Styles ship in Genesis and in `@formkit/theme-regenesis` 2.0.6. [Docs](https://formkit.com/inputs/datepicker#inline) &nbsp;-&nbsp; by @justin-schroeder in https://github.com/formkit/formkit/issues/1187 [<samp>(2d42b)</samp>](https://github.com/formkit/formkit/commit/2d42bbc9)

### &nbsp;&nbsp;&nbsp;🐞 Bug Fixes

- **datepicker**: A custom `#panelWrapper` slot no longer renders twice &nbsp;-&nbsp; by @justin-schroeder [<samp>(2d42b)</samp>](https://github.com/formkit/formkit/commit/2d42bbc9)
