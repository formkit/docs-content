## 0.134.1

### November 22, 2026

### &nbsp;&nbsp;&nbsp;🐞 Bug Fixes

- **datepicker**: Setting `v-model` to a string that doesn't match `value-format` (for example a stale stored value like `07/04/2024` with `value-format="YYYY-MM-DD"`) threw an uncaught `Date (…) does not match format (…)` error since `@formkit/tempo` 1.2.0's stricter parsing. It now renders an empty input and logs a warning, the same as on initial render; a valid value afterwards works normally. &nbsp;-&nbsp; by @justin-schroeder in https://github.com/formkit/pro/pull/111 [<samp>(d3581)</samp>](https://github.com/formkit/pro/commit/d3581973)
