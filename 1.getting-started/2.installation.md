# Installation

## Prerequisites

- :FrameworkText{vue="Vue 3+ or Nuxt 3+." react="React 18+ or Astro with React integration."}
- Vite (strongly recommended for automatic optimizations)
- Node.js `20` or higher (or whatever your framework/build tool requires — e.g. current Vite and Nuxt need Node 20+).
- Terminal: To run `npm`/`yarn`/`pnpm` commands.

::FrameworkOnly{framework="react"}
::Callout
---
type: "warning"
label: "React 18 StrictMode (development only)"
---
React 19 is recommended. On React 18, `<StrictMode>` re-renders components with fresh state in development, which can leave a duplicate FormKit node attached to a form (wrong values or failed submits in dev). Production builds are not affected, and React 19's StrictMode is fully supported. If you're on React 18 and see this in development, upgrade to React 19 or render your forms outside `<StrictMode>`. Tracked in [#1784](https://github.com/formkit/formkit/issues/1784).
::
